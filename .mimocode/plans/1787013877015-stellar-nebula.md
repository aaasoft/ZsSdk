# 计划：SendRequestAsync 自动推断 Response 类型

## 目标
简化 `SendRequestAsync` 调用方式，从双泛型改为单泛型（或无泛型），通过 Request 类型自动推断 Response 类型。

## 方案：使用 `IRequest<TResponse>` 接口

### 核心思路
1. 定义接口 `IRequest<TResponse>` 标记 Request 与 Response 的映射关系
2. 让所有 Request 类实现该接口
3. 新增 `SendRequestAsync<TResponse>(IRequest<TResponse>)` 重载方法

### 调用方式对比

**之前：**
```csharp
var response = await client.SendRequestAsync<GetSnRequest, GetSnResponse>(new GetSnRequest());
```

**之后：**
```csharp
var response = await client.SendRequestAsync(new GetSnRequest());
// 编译器自动推断 TResponse 为 GetSnResponse
```

## 修改文件

### 1. 新增 `ZsSdk/Models/IRequest.cs`
```csharp
namespace ZsSdk.Models;

public interface IRequest<TResponse> where TResponse : BaseResponse
{
}
```

### 2. 修改 `ZsSdk/ZsClient.cs`
新增重载方法：
```csharp
public async Task<TResponse> SendRequestAsync<TResponse>(
    IRequest<TResponse> request, 
    CancellationToken cancellationToken = default) 
    where TResponse : BaseResponse
{
    return await SendRequestAsync<IRequest<TResponse>, TResponse>(
        request, cancellationToken);
}
```

### 3. 修改所有 Request 类，实现 `IRequest<TResponse>` 接口

示例：
```csharp
// GetSnCommand.cs
public class GetSnRequest : BaseRequest, IRequest<GetSnResponse> { ... }

// IvsResultCommand.cs
public class IvsResultRequest : BaseRequest, IRequest<IvsResultResponse> { ... }
```
